# timepaw

一天不是一份清單，是一條散步的路。

單一個 HTML 檔，沒有任何相依套件、不用打包、不用伺服器。用瀏覽器打開就會動。

## 它做什麼

把「今天」攤成一條斜穿整個畫面的路，蓋在你頁面的最底層（不擋任何點擊）。

- 走過的那一段是**實線**，還沒走到的是**虛線**，交界處那顆會呼吸的點就是「現在」。時間自己會走，每分鐘重畫一次。
- 今天發生的每件事＝路上的一根 **📌**。點下去看那個時間你在幹嘛。
- 幾分鐘內連著發生的事，畫在路上會擠成一坨——所以靠太近的圖釘會**併成一根**，右上角標數字，點開就是那段時間裡的全部。
- **路每天長得不一樣**。用今天的日期當亂數種子，同一天不管重整幾次都是同一條，過了午夜就換一條新的。

## 怎麼用

1. 下載 `index.html`。
2. 打開最下面的 `daytlItems`，換成你自己的資料：

```js
const daytlItems = [
  { ts: '2026-08-16T11:33:00', text: '看她媽媽煮的麵，兩顆貢丸' },
  // ts 是時間（Date 吃得下的任何格式），text 是那一刻你在幹嘛
];
```

真的在用的時候，這串通常是從你自己的 API 撈回來的。換成一行 `fetch` 就好，其他都不用動。

## 可以調的地方

| 在哪 | 是什麼 |
| --- | --- |
| `dpNodesToday()` 裡的 `n` | 路有幾個轉折（預設每天隨機 3~5 個）。少一點＝彎更大更圓 |
| 分組那行的 `18` | 圖釘併在一起的距離（單位是路徑上的像素） |
| `:root` 那組變數 | 顏色。`--terra-deep` 是圖釘、`--paper` 是背景 |
| `.dp-node` | 圖釘長什麼樣。想換成自己的圖就把 `<text>` 換成 `<image>` |

## 它想給的感覺

那條線本身其實就是一種進度條——只是它不催你。

它給的感覺是「慢慢走過」：路每天長得不一樣、彎法不一樣、連長度都不一樣，時間自己一分一分往前挪。你不用做什麼，它也一直在走。看起來是愜意的，不是待辦的。

然後你可以隨手在路上留一根圖釘。多小的事都可以：挖到一張專輯、看了一碗麵、修好一個小毛病。那些不會被寫進任何日程表的東西，在這裡都留得下來——一天結束的時候回頭看，那條路上就是你真的走過的地方。
